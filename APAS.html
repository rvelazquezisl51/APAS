MethodMétodo

IAI = 70% API + 30% ASI. API = points / maximum points × 100; ASI = standards at level 3 or higher / total × 100; CDI = level 1 / total × 100. (Spanish abbreviations: IDA, ISA, IDC, IVI respectively for API, ASI, CDI, IAI.)

API = puntos / máximo × 100; ASI = estándares en nivel 3 o superior / total × 100; CDI = nivel 1 / total × 100.

A ≥ 93; B ≥ 79; C ≥ 50; D ≥ 21; F < 21. Comparisons use unrounded values. / Se utilizan valores sin redondear.
